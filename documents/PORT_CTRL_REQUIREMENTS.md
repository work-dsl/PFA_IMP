# 端口控制模块需求说明书

## 1. 模块概述

### 1.1 模块名称

端口控制模块（Port Control Module）

### 1.2 模块功能

端口控制模块负责管理系统中的电极开关、工作模式切换、导管类型选择和极性配置。该模块通过GPIO和TCA6424扩展芯片控制多个电极的开关状态，并根据不同的工作模式和导管类型应用相应的约束规则。

### 1.3 模块版本

V1.0

### 1.4 设计规范

- 遵循 MISRA C:2012 规范
- 使用 C99 标准
- 禁止使用动态内存分配（malloc、free）
- 最小化 RAM 和 Flash 占用
- 代码必须可预测，具有最小的运行时抖动

---

## 2. 功能需求

### 2.1 模块初始化

**需求 ID**: REQ-001

**功能描述**: 模块必须提供初始化接口，完成所有硬件资源的初始化配置。

**详细要求**:

- 初始化模式选择继电器GPIO（ECG_MAP、CONTACT_IMP、LOOP_IMP）
- 初始化极性选择继电器GPIO（负极板、顶电极极性、电杆极性）
- 初始化顶(网)电极控制GPIO
- 初始化TCA6424扩展芯片（I2C接口），该芯片用于控制电杆电极继电器通断

**约束规则**：

- 所有继电器默认状态为断开（输出高电平）

**返回值**:

- 0：初始化成功
- 负数：初始化失败，返回错误码

---

### 2.2 导管类型和极性选择

**需求 ID**: REQ-002

**功能描述**: 模块必须支持选择导管类型和极性配置，并验证配置的有效性。

**支持的导管类型**:

- `CATH_TYPE_PVI1`：PVI 一代导管
- `CATH_TYPE_PVI2`：PVI 二代导管
- `CATH_TYPE_FOCAL`：局灶导管

**支持的极性模式**:

- `CATH_POL_A`：负极板-断开，顶(网)电极极性-负，1-3-5杆极性-正（三个导管都支持）
- `CATH_POL_B`：负极板-导通，顶(网)电极极性-负，1-3-5杆极性-负（仅PVI2代/局灶）
- `CATH_POL_C`：负极板-断开，顶(网)电极极性-正，1-3-5杆极性-负（仅PVI2代/局灶）
- `CATH_POL_D`：负极板-断开，顶(网)电极极性-正，1-3-5杆极性-正（仅PVI2代）

**约束规则**:

- PVI1代导管仅支持 `CATH_POL_A`
- PVI2代导管支持 `CATH_POL_A`、`CATH_POL_B`、`CATH_POL_C`、`CATH_POL_D`
- 局灶导管支持 `CATH_POL_A`、`CATH_POL_B`、`CATH_POL_C`

**返回值**:

- 0：选择成功
- `-EINVAL`：导管类型和极性组合无效

**注意**:

- 此函数仅保存导管信息，不直接设置GPIO状态。极性选择GPIO的状态由工作模式决定。
- 若发生了导管切换且工作模式处于回路阻抗模式或消融模式，则需要进行电极约束的检查，若约束检查不通过，则需要应用约束条件。

---

### 2.3 工作模式设置

**需求 ID**: REQ-003

**功能描述**: 模块必须支持四种工作模式的切换，并根据模式自动配置相应的继电器和电极状态。

**支持的工作模式**:

1. **标测模式（PORT_MODE_MAPPING）**
   - 模式继电器：ECG_MAP=导通，CONTACT_IMP=断开，LOOP_IMP=断开
   - 极性选择GPIO：强制为1（保持断开状态）
   - 电极位图：强制为0（所有电极断开）

2. **贴靠阻抗检测模式（PORT_MODE_CONTACT_IMP）**
   - 模式继电器：ECG_MAP=断开，CONTACT_IMP=导通，LOOP_IMP=断开
   - 极性选择GPIO：强制为1（保持断开状态）
   - 电极位图：强制为0（所有电极断开）
   - **限制**: PVI1代导管不支持此模式

3. **回路阻抗检测模式（PORT_MODE_LOOP_IMP）**
   - 模式继电器：ECG_MAP=断开，CONTACT_IMP=断开，LOOP_IMP=导通
   - 极性选择GPIO：根据当前导管信息设置
   - 电极位图：应用预设位图

4. **消融模式（PORT_MODE_ABLATION）**
   - 模式继电器：ECG_MAP=断开，CONTACT_IMP=断开，LOOP_IMP=断开
   - 极性选择GPIO：根据当前导管信息设置
   - 电极位图：应用预设位图

**模式切换行为**:

- 切换到标测模式或贴靠模式时，自动将所有极性选择GPIO以及电极断开
- 切换到回路阻抗检测模式或消融模式时，自动应用预设的电极位图（如果存在）
- 在回路阻抗检测模式和消融模式下，自动设置极性选择GPIO

**返回值**:

- 0：模式设置成功
- `-EINVAL`：模式无效或导管不支持该模式

---

### 2.4 电极位图控制

**需求 ID**: REQ-004

**功能描述**: 模块必须支持通过32位位图控制25个电极的开关状态。

**电极位图定义**:

- `bit0`：顶(网)电极，使用GPIO控制
- `bit1-bit4`：1杆1电极~1杆4电极，映射到TCA6424 P00-P03
- `bit5-bit8`：3杆1电极~3杆4电极，映射到TCA6424 P04-P07
- `bit9-bit12`：5杆1电极~5杆4电极，映射到TCA6424 P10-P13
- `bit13-bit16`：2杆1电极~2杆4电极，映射到TCA6424 P14-P17
- `bit17-bit20`：4杆1电极~4杆4电极，映射到TCA6424 P20-P23
- `bit21-bit24`：6杆1电极~6杆4电极，映射到TCA6424 P24-P27
- `bit25-bit31`：保留

**位图控制逻辑**:

- **约束条件检查**:
  - 进行电极约束的检查：
    - 检查通过则将用户设置的原始位图保存到预设电极位图参数中
    - 不通过则丢弃用户设置的原始位图并返回错误码
  - 若工作模式恰好处于回路阻抗检测模式和消融模式，则立即控制硬件应用预设电极位图

**硬件控制规则**:

- TCA6424控制：低电平=导通，高电平=断开
- 顶电极GPIO控制：低电平=导通，高电平=断开

**返回值**:

- 0：控制成功
- 负数：返回错误码

---

### 2.5 电极约束规则

**需求 ID**: REQ-005

**功能描述**: 在控制电极位图时，必须根据导管类型和极性模式进行电极约束规则的判断并赋值给预设参数。

约束规则1：**局灶导管电极约束**

- **适用条件**: 导管类型为 `CATH_TYPE_FOCAL`
- **约束内容**: 1-6杆的3-4电极必须始终断开
- **影响的位**: bit3, bit4, bit7, bit8, bit11, bit12, bit15, bit16, bit19, bit20, bit23, bit24
- **掩码**: `0x00F8F8F8`

约束规则2：**PVI一代导管电极约束**

- **适用条件**: 导管类型为 `CATH_TYPE_PVI1`
- **约束内容**: 1-6杆的4电极必须始终断开
- **影响的位**: bit4, bit8, bit12, bit16, bit20, bit24
- **掩码**: `0x00111110`

约束规则3：**顶电极极性约束**

- **约束内容**:
  - `CATH_POL_A`：顶电极必须断开（bit0 = 0）
  - `CATH_POL_C`：顶电极必须导通（bit0 = 1）
  - `CATH_POL_D`：顶电极必须导通（bit0 = 1）
  - `CATH_POL_B`：不强制约束顶电极状态（由用户位图决定）

**约束检查时机**:

- 在 `port_ctrl_elec()` 函数中：需要判断用户传入的原始位图是否符合约束规则
- 预设位图保存在 `g_preset_elec_bitmap`，在消融模式或回路阻抗检测模式下应用预设位图用于硬件控制
- 导管切换时需要进行约束检查，若不通过，则应用约束规则修正电极位图

---

### 2.6 状态查询

**需求 ID**: REQ-006

**功能描述**: 模块必须提供接口查询当前导管信息和工作模式。

**查询接口**:

1. `port_ctrl_get_catheter()`：获取当前导管类型和极性信息
2. `port_ctrl_get_mode()`：获取当前工作模式

**返回值**:

- 返回当前状态的结构体指针或枚举值

## 3. 硬件接口定义

### 3.1 GPIO引脚定义

**模式选择继电器**:

- `ECG_MAP_RELAY_PIN_ID` (15/PA15)：心电标测继电器
- `CONTACT_IMP_RELAY_PIN_ID` (2/PA2)：贴靠阻抗继电器（可选，通过宏控制）
- `LOOP_IMP_RELAY_PIN_ID` (3/PA3)：回路阻抗继电器

**极性选择继电器**:

- `NEG_PLATE_RELAY_PIN_ID` (35/PC3)：负极板继电器
- `TOP_WIRE_POL_PIN_ID` (39/PC7)：顶(网)电极极性选择
- `POLE_POL_SELECT_PIN_ID` (32/PC0)：1-3-5电杆极性选择

**电极控制**:

- `TOP_WIRE_PIN_ID` (34/PC2)：顶(网)电极继电器

### 3.2 TCA6424扩展芯片

- **接口**: I2C1
- **地址**: TCA6424_I2C_ADDR_H
- **功能**: 控制24个电杆电极开关（1-6杆，每杆4个电极）
- **端口映射**: 见2.4节电极位图定义

### 3.3 继电器控制逻辑

- **低电平（0）**: 继电器导通
- **高电平（1）**: 继电器断开

### 3.4 电极开关控制逻辑

- **低电平（0）**: 电极导通
- **高电平（1）**: 电极断开

## 4. 数据结构和类型定义

### 4.1 导管类型枚举

```c
typedef enum {
    CATH_TYPE_PVI1 = 1,    /* PVI 一代 */
    CATH_TYPE_PVI2,        /* PVI 二代 */
    CATH_TYPE_FOCAL        /* 局灶 */
} cath_type_t;
```

### 4.2 导管极性枚举

```c
typedef enum {
    CATH_POL_A = 1,    /* 负极板-断开, 顶电极极性-负, 1-3-5杆极性-正 */
    CATH_POL_B,        /* 负极板-导通, 顶电极极性-负, 1-3-5杆极性-负 */
    CATH_POL_C,        /* 负极板-断开, 顶电极极性-正, 1-3-5杆极性-负 */
    CATH_POL_D         /* 负极板-断开, 顶电极极性-正, 1-3-5杆极性-正 */
} cath_pol_t;
```

### 4.3 导管结构体

```c
typedef struct {
    cath_type_t type;      /* 导管类型 */
    cath_pol_t  polarity;  /* 导管极性 */
} port_cath_t;
```

### 4.4 工作模式枚举

```c
typedef enum {
    PORT_MODE_MAPPING = 1,     /* 标测 */
    PORT_MODE_CONTACT_IMP,     /* 贴靠阻抗检测 */
    PORT_MODE_LOOP_IMP,        /* 回路阻抗检测 */
    PORT_MODE_ABLATION         /* 消融 */
} port_mode_t;
```

## 5. 接口函数定义

### 5.1 初始化接口

```c
int port_ctrl_init(void);
```

- **功能**: 初始化端口控制模块
- **返回值**: 0成功，负数表示错误码

### 5.2 导管选择接口

```c
int port_crtl_select_catheter(port_cath_t catheter);
```

- **功能**: 选择导管类型和极性
- **参数**: `catheter` - 导管信息结构体
- **返回值**: 0成功，`-EINVAL`表示参数无效

### 5.3 模式设置接口

```c
int port_ctrl_set_mode(port_mode_t mode);
```

- **功能**: 设置端口工作模式
- **参数**: `mode` - 工作模式枚举值
- **返回值**: 0成功，负数表示错误码

### 5.4 电极控制接口

```c
int port_ctrl_elec(uint32_t pole_elec_bitmap);
```

- **功能**: 控制电极位图
- **参数**: `pole_elec_bitmap` - 32位电极位图
- **返回值**: 0成功，负数表示错误码

### 5.5 状态查询接口

```c
const port_cath_t *port_ctrl_get_catheter(void);
port_mode_t port_ctrl_get_mode(void);
```

- **功能**: 查询当前导管信息和工作模式
- **返回值**: 导管信息结构体指针或工作模式枚举值

## 6. 状态管理

### 6.1 内部状态变量

- `g_current_catheter`: 当前导管信息（类型和极性）
- `g_current_work_mode`: 当前工作模式
- `g_last_elec_bitmap`: 上次应用的电极位图（用于去重判断）
- `g_preset_elec_bitmap`: 预设的电极位图（用户设置值）

### 6.2 状态转换规则

1. 导管选择后，状态立即更新，但不影响硬件
2. 模式切换时，根据新模式自动配置硬件
3. 电极位图设置时，根据当前模式决定是否控制硬件应用预设的电极位图

---

## 7. 错误处理

### 7.1 错误码定义

- `0`: 操作成功
- `-EINVAL`: 参数无效（如导管类型和极性不匹配、模式不支持等）

### 7.2 错误处理策略

- 所有接口函数在参数无效时返回 `-EINVAL`
- 硬件操作失败时返回相应的错误码
- 使用日志系统记录错误信息（LOG_E、LOG_W、LOG_I等）

---

## 8. 性能要求

### 8.1 响应时间

- 模式切换响应时间：< 10ms
- 电极位图更新响应时间：< 5ms

### 8.2 资源占用

- RAM占用：最小化，仅保存必要的状态变量
- Flash占用：最小化，代码精简高效
- 不使用动态内存分配

---

## 9. 安全要求

### 9.1 硬件安全

- 所有继电器默认状态为断开（安全状态）
- 模式切换时，确保先断开所有电极，再切换到新模式
- 在标测模式和贴靠模式下，强制所有电极断开

### 9.2 约束规则强制应用

- 在消融模式和回路阻抗检测模式下，约束规则必须强制应用
- 用户无法绕过约束规则直接控制硬件
- 约束规则在硬件控制前自动应用
